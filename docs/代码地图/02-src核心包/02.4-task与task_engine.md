### 🔴 1.9 `task/periodic_scheduler.py` — 空壳（27 行）

```python
class PeriodicScheduler:
    def __init__(self, *args, **kwargs):
        """Stub: 接受任意参数但不使用"""
        self._manager_stub = None
        pass
    async def start(self): pass
    async def stop(self): pass
    def set_manager_stub(self, manager_stub):
        self._manager_stub = manager_stub
        logger.info("✅ Manager Stub 已设置到定时任务调度器(Stub)")
```

| 项 | 内容 |
|---|---|
| 类型 | **空壳 STUB** |
| 规模 | 27 行 |
| 问题 | `start()` / `stop()` 全是 `pass`，**定时器根本不会运行任何任务** |
| 导出情况 | 被 `src/task/__init__.py:53` 正式导出为 `PeriodicScheduler` 与 `get_periodic_scheduler` |

| 风险 | 说明 |
|---|---|
| **定时任务完全不生效** | 任何注册到 `PeriodicScheduler` 的周期任务都不会被执行 |
| **日志具有欺骗性** | `set_manager_stub()` 会打印「✅ Manager Stub 已设置」，让运维以为配置成功 |
| 建议 | 要么实现，要么从 `__init__.py` 的导出中移除，避免误导 |
