| 层级 | 值 | 说明 |

> 该服务 4 个工具的 `description` 字段全是 **mojibake**（UTF-8 字节被当作 Latin-1 解码）：
> ```

### 1.4 `config/permissions.json`

```json
{
  "roles": {
    "admin": { "level": "write", "data_scope": "all" },
    "user":  { "level": "write", "data_scope": "own" },
    "guest": { "level": "read",  "data_scope": "own" }
  },
  "users": { "admin": "admin", "alice": "user", "test": "guest" },
  "default_role": "guest"
}
```

| 项 | 说明 |
|---|---|
| 模型 | 3 角色 × 2 维度（level: read/write × data_scope: all/own） |
| 用户 | **硬编码 3 个账号**，无密码（仅账号名 → 角色映射） |
| 默认角色 | `guest`（未注册用户落到 guest） |
| 热更新 | `UserService` 写配置后自动 `PermissionService().reload()`，**权限变更立即生效** |
| 适用 | 内网可信环境（无认证，靠 `X-User-Id` 请求头标识用户） |
