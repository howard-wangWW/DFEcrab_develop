# PDF 读取能力设计方案

## 1. 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    应用层                                │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────┐ │
│  │   TUI       │  │   CLI       │  │   REST API      │ │
│  └─────────────┘  └─────────────┘  └─────────────────┘ │
├─────────────────────────────────────────────────────────┤
│                    网关层 (Gateway)                      │
├─────────────────────────────────────────────────────────┤
│                    服务层 (Services)                     │
│  ┌─────────────────────────────────────────────────┐   │
│  │            PDFService (新增)                     │   │
│  │  文本提取 | 表格识别 | 图片提取 | 元数据          │   │
│  └─────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────┤
│                    技能层 (Skills)                       │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────┐ │

│                    引擎层 (Engines)                      │
│  ┌───────────┐ ┌───────────┐ ┌───────────┐            │

│  └───────────┘ └───────────┘ └───────────┘            │
└─────────────────────────────────────────────────────────┘
```

## 2. 支持的功能点

| 功能模块 | 功能点 | 说明 |
|---------|--------|------|
| **文本提取** | 全文提取 | 提取 PDF 所有文本内容 |
| | 按页提取 | 提取指定页码的文本 |
| | 按区域提取 | 提取指定坐标区域的文本 |
| **表格识别** | 表格检测 | 自动识别 PDF 中的表格 |
| | 表格提取 | 提取表格为 CSV/Excel |
| **图片提取** | 图片提取 | 提取 PDF 中嵌入的图片 |
| | 图片保存 | 保存为 PNG/JPG 格式 |
| **元数据** | 文档信息 | 作者、标题、创建时间等 |
| | 页面信息 | 总页数、页面尺寸 |
