# DFEcrab 部署与启动

> 路径固定 `/home/e8900`，按顺序执行即可

## 一、部署包解压

```bash
unzip DFEcrab.zip -d /home/e8900/DFEcrab
cd /home/e8900/DFEcrab
```

## 二、配置修改

### 1. Zookeeper 地址（gateway.yaml）

```bash
vi config/gateway.yaml
```

```yaml
zookeeper:
  hosts: 172.20.42.247:2181    # 改成你的 ZK 服务器地址
  namespace: dfecrab
```

### 2. 模型 API（dfecrab.json）

```bash
vi config/dfecrab.json
```

把要用的 provider 的 `api_base`、`model_name` 改成实际值，设 `enabled: true`，其他 provider 设 `enabled: false`。

## 三、权限修复

> zip 解压后会丢可执行权限，必须手动补回来

```bash
cd /home/e8900/DFEcrab

chmod +x dfecrab
chmod +x venv/bin/python3 venv/bin/python venv/bin/python3.12
chmod +x runtime/bin/node runtime/bin/node.real runtime/lib/ld-musl-x86_64.so.1
find . -name "*.sh" -exec chmod +x {} \;
chmod -R 755 logs/ knowledge_base/ data/ 2>/dev/null || true
```

### 验证权限 OK

```bash
./venv/bin/python3 --version
# Python 3.12.x

./dfecrab --version
# 4.0.0-grpc

/home/e8900/DFEcrab/runtime/lib/ld-musl-x86_64.so.1 \
  --library-path /home/e8900/DFEcrab/runtime/lib:/home/e8900/DFEcrab/runtime/usr/lib \
  /home/e8900/DFEcrab/runtime/bin/node.real --version
# v24.16.0
```

## 四、启动 Zookeeper

```bash
cd /home/e8900/apache-zookeeper-3.8.4-bin
./bin/zkServer.sh start
./bin/zkServer.sh status
# mode: standalone 或 leader 表示 OK
```

## 五、启动 DFEcrab

```bash
cd /home/e8900/DFEcrab

# 一键启动全部
./dfecrab start

# 查看状态
./dfecrab status

# 停止全部
./dfecrab stopall

# 命令帮助
./dfecrab --help
```
