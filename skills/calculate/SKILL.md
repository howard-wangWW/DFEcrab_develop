# Calculate

计算数学表达式的技能。

## When to Use

当用户需要进行数学计算时使用，例如：
- 基础运算：2 + 3 * 4
- 复杂表达式：(10 + 5) * 2 / 3
- 数学函数：abs(-5), min(3, 7), max(2, 9)

## When NOT to Use

不需要使用工具的简单计算时不要使用。
