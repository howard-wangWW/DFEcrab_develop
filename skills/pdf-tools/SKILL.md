# PDF 工具技能

提供常用的 PDF 处理功能。

## When to Use
- 旋转 PDF 页面（90/180/270 度）
- 合并多个 PDF 文件
- 拆分 PDF 文件

## When NOT to Use
- 加密/解密 PDF（需要密码）
- PDF 文本提取（使用 OCR 技能）
