# ASR拼音纠错技能 (asr_corrector)

## 功能
纠正ASR（自动语音识别）识别错误的文本。当用户输入是语音转文字结果时，由于同音词等问题可能导致识别错误，此技能提供两层纠错机制：

1. **拼音匹配（快速）**：用拼音匹配常见的ASR错误模式
2. **模型纠错（兜底）**：当拼音匹配失败时，调用LLM模型进行语义纠错

## 使用场景
- 用户通过语音输入，ASR识别结果可能包含同音错误
- 电力调度专业术语被错误识别（如"重过载"被识别为"重过灾"）

## 纠错范围
- 电力调度核心术语：重过载、保供电、受令资格、跳闸、异常信号等
- 供电局/设备名称：西山局、官渡局等

## 调用方式
```python
# 输入：ASR识别的原始文本
corrected = asr_corrector.execute(text="重过灾是哪里的？")
# 输出：纠正后的文本
```

## 参数
- `text`: ASR识别的原始文本（必填）
- `use_model`: 拼音匹配失败时是否使用模型兜底（默认true）

## 返回
- `corrected_text`: 纠正后的文本
- `corrections`: 具体的纠错记录列表
