# Image Gen

调用图片模型（OpenAI 兼容 `/images/generations`）根据文本描述生成图片。

## When to Use

当用户要求"画/生成/做一张图片、插画、配图、海报底图"等视觉内容时使用，例如：

- "帮我画一只在草地上奔跑的柯基犬"
- "给这个方案生成一张科技风配图"
- "生成一张 1024x1024 的极简风格图标"

## 使用要点

- `prompt` 必填，尽量写清**主体 + 风格 + 构图 + 光线**，描述越具体效果越稳定。
- `size` 只能取 `512x512` / `768x768` / `1024x1024` / `1024x1536` / `1536x1024`，其它值会被自动回落。
- `n` 为生成张数，默认 1，最大 4（受配置 `image_generation.max_n` 限制）。
- 工具返回 JSON，其中 `display` 字段是可直接使用的 Markdown 图片语法；
  在回复中展示图片时**只输出该 Markdown**，不要把 base64 或完整 JSON 贴给用户。
- 若返回 `{"success": false, "error": "..."}`，说明图片服务未配置或不可用，
  请把错误信息如实告知用户，不要编造图片地址。

## When NOT to Use

- 用户只是想要**图表 / 流程图 / 架构图**时，优先用代码生成（Mermaid、HTML），不要调用本技能。
- 用户没有明确要"图片"这一交付形态时，不要主动生成。
