# 电力系统专家 - 达梦数据库查询技能

## 技能名称
`dm-test`

## 描述
该技能用于连接达梦数据库（DM8），查询电力系统相关的三个核心表：
- `AI_ANALYSE_PB`    （保护装置分析数据）
- `AI_ANALYSE_FEEDER`（馈线分析数据）
- `IFA_INDEX`        （综合故障分析指标）

数据库连接信息：
- 服务器地址：172.20.42.247
- 模式（Schema）：XOPENS

## 使用场景
- 电力调度员需要获取某时段内的保护动作记录
- 分析馈线负载率或故障特征
- 查询综合故障指标用于态势感知

## 指令示例
用户可说出如下指令：
- “查询 AI_ANALYSE_PB 表最新 10 条记录”
- “统计 IFA_INDEX 表中本月平均指标值”
- “导出 AI_ANALYSE_FEEDER 表 2025-01-01 之后的数据”
- “查询配变重过载数据” -> 需要查询 `AI_ANALYSE_PB` 表中过载相关字段
- “查询馈线故障率” -> 需要查询 `AI_ANALYSE_FEEDER` 表中过载相关字段
- “查询线路跳闸数据” -> 需要查询 `IFA_INDEX` 表中跳闸相关字段

## 实现细节
- 底层使用 `dmPython` 驱动连接达梦数据库
- 配置文件从 `.env` 读取用户名、密码等敏感信息
- 查询结果以表格或 JSON 格式返回

## 注意事项
- 执行前请确保网络可达 `172.20.42.247:5236`（达梦默认端口）
- 不要在日志中打印密码
- 大量数据查询请添加 LIMIT 条件
