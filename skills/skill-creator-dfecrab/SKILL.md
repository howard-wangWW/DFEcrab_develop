# Skill Creator - DFEcrab

快速创建符合 OpenClaw 标准的技能。

## 使用方法

```
创建一个叫 [技能名] 的技能，描述是 [描述]
```

## 功能

- 自动生成技能目录结构
- 创建标准的 SKILL.md 文件
- 生成 execute.py 骨架代码
- 可选：添加 src/ 目录结构
