# /review - 代码审查

执行全面的代码审查，检查以下方面：

## 审查流程

### 1. 代码质量
- 检查命名规范
- 检查代码复杂度
- 检查重复代码
- 检查注释质量

### 2. 安全问题
- 检查敏感信息泄露
- 检查输入验证
- 检查权限控制

### 3. 性能问题
- 检查循环效率
- 检查内存使用
- 检查数据库查询

### 4. 最佳实践
- 检查设计模式使用
- 检查错误处理
- 检查日志记录

## 输出格式

```
## 审查结果

### 问题列表
| 文件 | 行号 | 严重性 | 问题描述 | 建议 |
|------|------|--------|----------|------|

### 统计
- 总问题数: X
- 高危: X
- 中危: X
- 低危: X

### 建议
[改进建议]
```

## 参数

- `files`: 指定要审查的文件或目录（可选）
- `--fix`: 自动修复可修复的问题（可选）

## 示例

```bash
/review                          # 审查当前目录
/review src/core/               # 审查指定目录
/review src/main.py --fix       # 审查并修复
```
