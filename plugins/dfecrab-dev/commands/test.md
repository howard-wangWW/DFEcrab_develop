# /test - 运行测试

运行项目的测试套件并生成报告。

## 执行步骤

1. **发现测试**
   - 扫描 `tests/` 目录
   - 识别测试文件 (`test_*.py`, `*_test.py`)

2. **运行测试**
   ```bash
   pytest tests/ -v --cov=src --cov-report=term-missing
   ```

3. **生成报告**
   - 测试通过率
   - 覆盖率统计
   - 失败用例详情

## 输出格式

```
## 测试报告

### 概览
- 总用例: X
- 通过: X
- 失败: X
- 跳过: X
- 覆盖率: X%

### 失败用例
[详细失败信息]

### 覆盖率详情
| 模块 | 语句数 | 覆盖数 | 覆盖率 |
|------|--------|--------|--------|

### 建议
[提高覆盖率的建议]
```

## 参数

- `--watch`: 监听模式，文件变化时自动运行
- `--coverage`: 显示覆盖率报告
- `--failed`: 只运行失败的测试

## 示例

```bash
/test                    # 运行所有测试
/test --coverage        # 运行测试并显示覆盖率
/test tests/core/       # 运行指定目录的测试
```
