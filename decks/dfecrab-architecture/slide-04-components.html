🧩 核心组件

🌐 Gateway

  • HTTP API 服务 (6789)
  • Session 生命周期管理
  • 请求增强（添加上下文）
  • 定时任务调度
  • 调用 Manager Agent

🧠 Manager Agent

  • 意图识别（简单/复杂）
  • 任务分流策略
  • 多 Agent 工作流编排
  • 审计日志记录
  • Zookeeper 服务发现

🤖 Worker Agents

  • Analyst: 数据分析
  • Reporter: 报告生成
  • FileManager: 文件管理
  • 独立进程，随机端口
  • Zookeeper 自动注册

📋 Session Manager

  • 创建/查找 Session
  • 自动生成摘要
  • 加载历史上下文
  • 持久化存储
  • 过期自动清理
