🧠 记忆体系设计

短期记忆（会话级）

Session 级别
  • 保存当前对话历史（最近 100 条消息）
  • 每次请求自动加载上下文
  • 支持多会话独立管理
  • 用途：连续对话、上下文理解

长期记忆（Agent 级）

Agent 级别
  • 成功经验模式（successful_patterns）
  • 专业知识沉淀（professional_knowledge）
  • 失败教训记录（lessons_learned）
  • 用途：自进化、能力提升

全局共享记忆

全局共享
  • 电网知识库（grid_knowledge）
  • 术语库、模板库
  • 所有 Agent 共享访问
  • 用途：跨 Agent 知识复用
